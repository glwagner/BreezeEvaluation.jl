# Matched filtered-wall GABLS1 evaluation

This case tests whether temporal filtering of the fields used by the surface-exchange boundary condition improves GABLS1 near-wall shear. It retains the existing 32³, 400 m, WENO9, seed-123, nine-hour setup and the original rough-wall Monin–Obukhov coefficients. The two new treatments are filtered wall exchange with no interior closure and filtered wall exchange with one-face, scheme-native SurfaceLayerDiffusivity. The existing unfiltered no-closure and scheme-native SLD runs are controls.

The wall filter is Breeze's `FilteredSurfaceVelocities` with a 300 s timescale and matching height at the first cell center. One shared object supplies filtered u, v and the dry potential-temperature difference to `BulkDrag` and `BulkSensibleHeatFlux`. The GABLS adapter extends the historical dry rough-wall coefficient to consume the filtered wind and temperature difference. For the cooling surface, the heat flux uses the same filtered temperature difference as the stability coefficient; otherwise filtering θ and subtracting the current surface θ would introduce a cooling-rate-dependent lag mismatch. Surface density still uses current pressure and surface temperature.

The `wall_filter` JLD2 output saves the actual filtered state at 600 s intervals. Provenance records the adapter source and filter duration. Validation must check finite states, exact initialization digest, consistent u/v/heat flux signs and shared coefficient evaluation, filter evolution, source hashes, CASE_DONE and durable Slurm exit before comparison. Compare both 7–8 h and 8–9 h windows with the 1 m LES median. Report wall friction velocity, heat flux, wall-stress/first-cell-velocity correlation, first-face mean shear, resolved/numerical/SGS momentum flux partition, turbulence variances and low-level jet. A result is conditional on this one seed and does not prove the smooth-wall log-layer mismatch mechanism applies to a stable rough wall.
